# Dra.Gracielle

Site da Dra. Gracieli Sari, fisioterapeuta e osteopata em Porto Alegre.

## Arquivos

- `index.html`: conteúdo da página.
- `styles.css`: estilos.
- `script.js`: interações e formulário de contato.
- `tailwind-config.js`: configuração do Tailwind CSS.
- `assets/`: imagens e vídeos usados no site.

Abra a página por um servidor HTTP local. O site utiliza Google Fonts, Tailwind, Instagram e Google Maps via serviços externos.

## Vídeos

Os arquivos MP4 são otimizados para a web e versionados diretamente no Git, sem necessidade de Git LFS. A pasta `Conteudo/` contém originais locais e não é enviada ao repositório.
